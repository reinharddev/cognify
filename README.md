# Cognify

Cognify: manajemen catatan dan alat lokal, offline. Dokumen, papan, tabel, kalender, dan kotak alat (konversi, kompres, edit PDF dan media) yang berjalan di komputermu sendiri.

Cognify: local, offline notes and tools. Documents, boards, tables, a calendar, and a toolbox (convert, compress, edit PDFs and media) that runs on your own computer.

Tauri 2 (Rust) + SvelteKit (Svelte 5). Lisensi / License: AGPL-3.0-only (lihat / see `LICENSE`, `THIRD_PARTY_NOTICES.md`).

## Status

Versi awal. Utama di macOS; dukungan Windows sedang dibangun (build uji lewat Actions > Build Windows).
Early version. Primarily macOS; Windows support is in progress (test builds via Actions > Build Windows).

## Menjalankan / Running

```
npm install
npm run tauri -- dev
```
